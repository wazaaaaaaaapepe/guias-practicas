# 3 tareas de Excel que puedes automatizar con Python hoy

Si repites la misma tarea en Excel cada semana, Python la hace en segundos.

## 1. Limpiar duplicados y filas vacias
Con la libreria csv o pandas quitas duplicados de un archivo de miles de filas en un solo comando.

## 2. Juntar varios archivos en uno
Un script lee todos los CSV de una carpeta y los une en un solo archivo, sin copiar y pegar.

## 3. Generar un reporte automatico
Calcula totales por categoria y guarda el resultado en un archivo nuevo cada vez que lo ejecutas.
